# 🩺 MediScan AI

### AI-Powered Medical Report Analyzer

> **Turning complex medical reports into simple, understandable insights.**

🔗 **Live Demo:** https://medi-scan-a-i.lovable.app/

## 🧠 About

**MediScan AI** is an AI-powered HealthTech application that helps users understand medical and laboratory reports. It extracts important information from uploaded reports, analyzes test results, identifies abnormal values, and explains medical terminology in simple language.

The goal is to bridge the gap between **complex medical information and patient understanding**.

## ✨ Features

* 📄 Upload and analyze medical reports
* 🔍 OCR-based text extraction
* 🧪 Extract parameters, values, units & reference ranges
* 🟢 Identify normal, abnormal, and attention-needed results
* 🧠 Detect and explain medical terms such as **tumor, meningioma, cyst, lesion, nodule**, and more
* 📋 Generate a clear overall report summary
* 💡 Explain possible significance of detected findings
* ⚠️ Distinguish between reported findings and confirmed diagnoses

## 🔄 How It Works

**Upload Report → OCR Extraction → Data Analysis → Medical Term Detection → AI Explanation → Report Summary**

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS
**Backend:** Python, FastAPI
**AI & Processing:** OCR, NLP, AI-based analysis
**Database:** SQLite
**Tools:** Git, GitHub

## 🎯 Purpose

MediScan AI is designed to make medical reports **more accessible and easier to understand**, especially for users who may not be familiar with medical terminology or laboratory values.
